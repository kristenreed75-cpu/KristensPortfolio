Project 1
Arch Studios

This project explores the creation of an early‑stage architecture based app aimed at simplifying parts of the design process. The goal was to build a lightweight, organized space where architects can sketch ideas, gather site information, store project details, and generate quick cost or timeline estimates without switching between multiple tools.

UX/UI Designer · Researcher · Prototype Developer Figma, Windows Notepad, & Manual Sketching

Early‑stage architectural design relies heavily on speed, sketching, and fluid idea exploration, but most existing software slows architects down with rigid interfaces and technical steps. Through research into design behavior and current software, I found that architects often switch between multiple apps just to sketch, store files, or check basic project information. This fragmentation disrupts creative flow and makes early design more complicated than it needs to be. These insights shaped the direction of the prototype, focusing on simplicity, fast access to information, and a workspace that supports the nonlinear way architects actually work.

Early‑stage architectural design needs tools that support fast thinking and fluid exploration, so each feature was built to reduce friction in that workflow. The sketching workspace offers a simple, pen‑and‑paper‑style environment for quick concept development, while the project info panel keeps site data, notes, and references in one place to prevent constant app‑switching. A quick‑estimate tool provides rough cost and timeline projections to support early feasibility discussions. Together, these features create a lightweight, organized space that aligns with how architects work at the start of a project.
