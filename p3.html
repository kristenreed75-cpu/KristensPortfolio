Custom Card Creator

This project is a multi‑template card generator built with HTML, CSS, and JavaScript. Users can choose from several card types such as employee badges, sports cards, influencer profiles, student IDs, and business cards, and generate a customized design instantly. The generator focuses on simplicity, clean visuals, and flexible layouts that adapt to different card formats.

UI Design ·HTML · CSS · JavaScript

I began by designing a clean landing page with a grid of buttons that let users select the type of card they want to generate. Each card type loads its own fields using JavaScript and stores user input through LocalStorage so the final card can be rendered on a separate page. I built reusable components for photos, text fields, banners, and color selectors, allowing each card to share a consistent structure while still supporting unique layouts. The design uses soft blues, rounded corners, and wave‑style backgrounds to create a friendly, modern aesthetic.

The generator’s strongest feature is its dynamic rendering system. Each card automatically pulls user data—names, titles, stats, social handles, or business info—and displays it inside a polished card layout. Users can also customize the top and bottom wave colors using interactive color selectors. The final card includes a photo, structured text, and a clean visual hierarchy, making each template feel professional and personalized. This project highlights modular UI design, responsive styling, and practical JavaScript logic for real‑time customization.
