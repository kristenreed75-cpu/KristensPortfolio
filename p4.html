Adventure Calc

This project focused on designing and coding a multi‑form Windows application with a clean, consistent interface. The main form served as the navigation hub, allowing users to move between scuba, skydiving, and help pages. Each activity form included its own calculation logic, input fields, and buttons, while maintaining a unified visual style across the entire application. The goal was to create a simple, user‑friendly program that handled cost calculations and navigation smoothly

UX/UI Designer · Visual Studios

I began by building the main form using a MenuStrip to link each tab to its corresponding form and coding the Exit option to close the program. After designing the home screen with an image and title label, I created the scuba form using labels, a textbox, and buttons for calculating totals, resetting the form, and returning home. I wrote separate methods to calculate the subtotal, apply discounts for groups of six or more, and compute the final total. The skydiving form followed the same structure, with the only change being the cost multiplier. Finally, I designed the help form with a single instructional label and a button that returned users to the home page.

The application’s strongest feature is its consistent, easy‑to‑navigate design. All forms share the same mint‑green background, matching fonts, and clear layout, creating a cohesive experience. The calculation methods are cleanly separated, making the logic easy to follow and maintain. Buttons provide straightforward actions, while labels clearly display results. The help form adds accessibility by giving users simple instructions and a quick way back to the home screen. Overall, the project demonstrates structured form design, organized code, and a user‑friendly interface..
